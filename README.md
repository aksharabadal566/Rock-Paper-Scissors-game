# ✊✋✌️ Rock Paper Scissors Game

> A classic **Rock Paper Scissors** game built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies, just fun!

---

## 📌 What is this?

A clean, browser-based implementation of the timeless **Rock Paper Scissors** game. Play against the computer which picks its choice randomly, and see the result instantly on screen!

---

## ✨ Features

- 🎮 **3 choices** — Rock, Paper, Scissors buttons
- 🤖 **Computer AI** — randomized computer choice every round
- ⚡ **Instant result** — win/lose/tie displayed right away
- 🎨 **Clean UI** — warm background with styled buttons
- 📱 **No setup needed** — just open the HTML file in any browser

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML5 | Structure & layout |
| CSS (Inline) | Styling & colors |
| Vanilla JavaScript | Game logic |

## 🚀 Getting Started

No installation needed!

```bash
git clone https://github.com/aksharabadal566/Rock-Paper-Scissors-game.git
cd Rock-Paper-Scissors-game
```

Then just open `index.html` in your browser. That's it! 🎉

---

## 🎮 How It Works

```
User clicks a choice (Rock / Paper / Scissors)
             ↓
Computer randomly picks from [rock, paper, scissors]
             ↓
Compare choices using game rules
             ↓
Display: Your choice | Computer's choice | Result
```

**Game Rules:**
- 🪨 Rock beats ✌️ Scissors
- ✋ Paper beats 🪨 Rock
- ✌️ Scissors beats ✋ Paper
- Same choice = 🤝 Tie
